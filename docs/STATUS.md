## What "reviewed" means here

- **Reviewed** — someone read the content against the source material, and looked at the rendered
  PDF for layout and page-break problems.
- **Unreviewed** — the YAML renders and passes the automated checks (`uv run poe check`), but that
  only proves the pipeline works; it says nothing about whether the rules text is correct.
